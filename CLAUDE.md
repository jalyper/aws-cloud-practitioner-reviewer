# AWS Cloud Practitioner Reviewer

Static quiz app for the AWS Certified Cloud Practitioner exam: `aws-flashcards-app/` (`index.html`, `script.js`, `styles.css`, `questions.js`). No build step; open `aws-flashcards-app/index.html` in a browser.

## Status

Finished. No planned work. Only fix reported bugs or question errors.

The Kiro spec for a larger "interactive learning platform" that was drafted here in July 2025 is preserved in the tag `archive/wip/uncommitted-2025-07-16` (`.kiro/specs/interactive-learning-platform/`). That platform is the separate `cheetcode` repo, which carries a copy of the spec in `docs/spec/`.

## The remote is the source of truth

- GitHub (`origin`) holds the truth. Local work may replace it only when it was made on top of its latest.
- Fetch before changing anything. If this copy is behind, bring it up to date first (fast-forward, or rebase your own commits onto origin). Never force-push, and never overwrite a remote change you have not seen.
- If the remote moved and the work cannot be brought on top of it cleanly, stop and ask.
- Push what you commit as soon as it is ready (in a cloud session: to your working branch).
